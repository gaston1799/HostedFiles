# MooMoo Script Guidelines

This directory holds the new MooMoo.io bot implementation.
When modifying files here:

- Use modern JavaScript (ES6+) with semicolons and strict mode.
- Keep code modular and well commented. Functions should be short and clear.
- Reference `PROJECT NOZO By gaston.user.js` for existing behaviour but copy it
  gradually. Implement small parts in each update rather than dumping the entire
  file at once.
- After making changes run `npm test` from the repository root.
- Document any new features in `README.md`.
